# 육십갑자 — 순행 · 역행 · 뒤집기 암송

고급 명리학자를 위한 육십갑자 암송 앱(안드로이드). 광고·로그인·인터넷 연결 없이 작동합니다.

## 설치 (안드로이드 폰)

**① 폰에서 아래 링크를 누르거나 QR코드를 찍습니다.**

👉 **[gapja60.apk 내려받기](https://github.com/eddan1000-del/gapja60/releases/latest/download/gapja60.apk)**

<img src="docs/qr.png" width="220" alt="APK 내려받기 QR코드">

**② 내려받은 파일을 엽니다.** (알림창의 '다운로드 완료' 또는 '내 파일 › 다운로드')

**③ '출처를 알 수 없는 앱' 허용** — 처음 한 번만 묻습니다.
"보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없습니다" → **설정** → **이 출처 허용** 켜기 → 뒤로 → **설치**

**④ 처음 실행하면 1~2분 동안 음성을 준비합니다.** 폰의 구글 한국어 음성으로 120개 낭독 파일을 한 번 만들어 저장하고, 이후에는 그 파일로 재생합니다.
- '한국어 음성 데이터가 없습니다'가 나오면 **음성 데이터 설치**를 눌러 한국어를 내려받은 뒤 **다시 시도**.

새 버전도 같은 링크로 받아 덮어 설치하면 기록이 그대로 유지됩니다.

## 기능
- **네 방향** (6×10 표: 가로 한 줄 = 한 순, 세로 한 열 = 같은 천간)
  - 순행: 가로로 갑자 → 을축 → … → 계해
  - 역행: 가로로 계해 → 임술 → … → 갑자
  - 순행 뒤집기: 세로로 위→아래. 갑자 → 갑술 → 갑신 → 갑오 → 갑진 → 갑인, 이어서 을축 → … → 을묘, … 계유 → … → 계해
  - 역행 뒤집기: 세로로 아래→위. 갑인 → 갑진 → 갑오 → 갑신 → 갑술 → 갑자, 이어서 을묘 → … → 을축, … 계해 → … → 계유
- **목소리 4종**: 여성 차분 · 여성 또렷 · 남성 저음 · 남성 또렷 (+ 기기 기본). 미리 듣기 후 선택. 높은 톤을 피하도록 음높이를 낮추고 60개 음량·앞뒤 무음을 고르게 맞춤
- **수면 모드**: 0.8배속·간격 1.5초·효과음 없음·무한 반복, 타이머 끝에 1~3분 동안 소리를 서서히 줄여 멈춤, 화면 밝기 최소
- **화면 색**: 낮(미색) · 밤(따뜻한 짙은 회색, 기본) · 수면(검은 갈색 + 어두운 호박색). 순수 흰색·검정 없음, 낮은 채도의 황토색 강조, 본문 대비 약 8:1
- **암송**: 시작 간지 지정(표의 칸 누르기), 6순 구간 선택, A–B 구간, 반복 1/3/5/무한, 잠들기 타이머
- **빈칸**: 일부를 '틱' 소리로 비우고 생각 시간 뒤 정답. 두 번 연속 성공하면 빈칸 10% 증가
- **잇기**(이어 말하기): 앞 간지 1~3개를 듣고 다음 간지 고르기. 자주 틀린 간지를 더 자주 출제
- **기록**: 연속 학습일, 총 학습 시간, 방향별 완주 횟수, 막히는 간지 표시
- **속도 0.5~5배**(0.25 단위, 음높이 유지). 간지 사이 간격도 배속에 비례해 줄어듦
- 화면을 꺼도 재생, 잠금화면·블루투스 이어폰 버튼 조작, 전화가 오면 멈춤 후 재개
- 한글 · 한자 · 병기 표기, 밝게/어둡게

## 음성을 성우 녹음으로 바꾸려면
`app/src/main/assets/voice/<버전 id>/`(f_calm, f_clear, m_low, m_clear, default)에 아래 61개 wav 파일을 넣고 다시 빌드하면 그 버전은 기기 음성 대신 그 파일을 씁니다.
- `f_00.wav` ~ `f_59.wav`: 갑자 … 계해 (번호 0=갑자, 가로 순서)
- `next.wav`: "다음은?"

## 개발
- Kotlin · Jetpack Compose(Material 3) · AndroidX Media3(ExoPlayer, MediaSessionService)
- `main`에 올리면 GitHub Actions가 단위 테스트(네 방향 240항목 전수 검사) → 서명된 APK 빌드 → 인터넷 권한 없음 확인 → 릴리스 게시
- 서명 키는 `keystore/release.jks` (개인용 배포 편의를 위해 저장소에 포함). 널리 배포할 때는 새 키를 만들어 저장소 Secrets(`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`)로 옮기고 이 파일은 지우세요.
